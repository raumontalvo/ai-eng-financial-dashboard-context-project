# Product Description

This project is a financial metrics dashboard that visualizes business financial movement data.

The application allows users to view high-level financial performance through:
- total income
- total outcome
- profit
- profit margin
- income vs outcome charting
- monthly profit percentage charting

The current repository uses mock generated financial data rather than a persistent database. The backend exposes API endpoints for financial movements, summaries, comparisons, alerts, facets, and B2B/B2C segmentation.

The project purpose is not only the dashboard itself, but also the creation of maintainability documentation and governance rules for future contributors.
