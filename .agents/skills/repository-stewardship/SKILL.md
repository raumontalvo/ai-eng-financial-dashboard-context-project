# Repository Stewardship Skill

## Purpose

This skill guides contributors and AI agents working on repository governance, maintainability analysis, and project memory generation.

## Responsibilities

- Inspect repository structure before making changes
- Validate AI-generated summaries against real code evidence
- Preserve actionable documentation
- Maintain governance rules inside `.agents/rules`
- Update `memory-bank` documents when repository behavior changes
- Keep commit history separated by project phase

## Validation Workflow

Before final submission or major repository changes:

- inspect backend and frontend structure
- review rule applicability
- verify tests/build checks
- confirm memory-bank accuracy
- confirm documentation remains repository-specific
