# Financial Dashboard Formatting

## Objective
Improve consistency and clarity in financial dashboard data presentation.

## Apply When
Use this skill when reviewing KPI cards, charts, tables, or summaries that display financial metrics.

## Instructions
- Format currency values consistently.
- Show percentage changes with clear positive/negative signs.
- Make negative values visually and semantically clear.
- Use consistent date and month labels across charts.
- Ensure loading, empty, and error states use consistent wording.
- Do not change calculations unless a verified bug exists.

## Acceptance Criteria
- Currency, percentages, and dates are formatted consistently.
- Negative values are easy to identify.
- Empty/loading/error states are clear.
- No business logic is rewritten without evidence.
